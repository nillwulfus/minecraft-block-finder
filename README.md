# Block Finder Mod для Minecraft 1.21.11

Клиентский мод для Fabric, который помогает находить и подсвечивать блоки в мире Minecraft.

## Возможности

- 🔍 **Поиск блоков** - найдите нужные блоки в загруженных чанках
- 💡 **Подсветка блоков** - выделение найденных блоков цветом
- 🌈 **Настройка цвета** - индивидуальный цвет для каждого типа блока
- 👁️ **Режим сквозь стены** - видимость блоков через препятствия
- 📍 **Координаты** - отображение координат найденных блоков
- 🎨 **Режимы отображения** - заливка, контур или оба варианта
- ⚙️ **Настройки** - гибкая настройка радиуса поиска, прозрачности и других параметров

## Требования

- Minecraft 1.21.11
- Fabric Loader 0.18.4+
- Fabric API 0.141.1+1.21.11

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/)
2. Скачайте [Fabric API](https://modrinth.com/mod/fabric-api)
3. Скачайте последнюю версию мода из [Releases](../../releases)
4. Поместите файл `.jar` в папку `mods` в директории Minecraft

## Использование

### Команды

- `/blockfinder` - открыть меню настроек
- `/blockfinder add <блок>` - добавить блок для поиска
- `/blockfinder remove <блок>` - удалить блок из поиска
- `/blockfinder clear` - очистить список поиска
- `/blockfinder list` - показать список искомых блоков
- `/blockfinder toggle` - включить/выключить мод
- `/blockfinder radius <число>` - установить радиус поиска

### Настройки

В меню настроек (`/blockfinder`) вы можете:
- Добавлять/удалять блоки для поиска
- Настраивать цвет подсветки для каждого блока
- Изменять радиус поиска (16-256 блоков)
- Переключать режим отображения (заливка/контур/оба)
- Включать/выключать режим "сквозь стены"
- Настраивать прозрачность подсветки

## Сборка из исходников

```bash
./gradlew build
```

Собранный мод будет находиться в `build/libs/`

## Технические детали

- Мод полностью клиентский и не требует установки на сервере
- Поиск происходит только в загруженных чанках
- Оптимизирован для минимального влияния на производительность
- Использует пользовательский render pipeline для отображения через стены
